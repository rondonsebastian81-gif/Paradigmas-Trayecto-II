Teoría del DOM (Modelo de Objetos del Documento)

¿Qué es el DOM?

El DOM (Document Object Model) es una interfaz de programación que representa un documento HTML como un árbol de objetos. Gracias a él, un lenguaje como JavaScript puede leer, modificar, añadir o eliminar la estructura, el contenido y el estilo de una página web en tiempo real.

En otras palabras: el navegador convierte tu HTML en un conjunto de nodos que podemos manipular con código. El DOM no forma parte de JavaScript ni de HTML, sino que es el puente que los conecta.

Ejemplo de la separación de capas: estructura (HTML), presentación (CSS) y comportamiento (JS).

El árbol de nodos

Todo en el documento es un nodo. Al abrir una etiqueta dentro de otra se crea una relación padre → hijo, formando un árbol:

document
 └── html
      ├── head
      │    └── title
      └── body
           ├── h1
           └── p

Tipos de nodos principales

  • Document: el punto de entrada; representa toda la página.
  • Element Node: cada etiqueta HTML (<div>, <p>, <input>…).
  • Text Node: el texto contenido dentro de un elemento.
  • Attribute Node: los atributos de una etiqueta (id, class, href…).

Seleccionar elementos

MétodoQué devuelve
document.getElementById("id")Un único elemento por su id.
document.querySelector("css")El primer elemento que coincide con un selector CSS.
document.querySelectorAll("css")Una lista con todos los elementos que coinciden.
document.getElementsByClassName("clase")Elementos que tienen cierta clase.

Modificar el documento

Una vez seleccionado un nodo podemos cambiar su contenido, sus atributos o sus estilos:

const titulo = document.getElementById("titulo");

titulo.textContent = "Nuevo texto";     // cambia el texto
titulo.innerHTML   = "<strong>Hola</strong>"; // inserta HTML
titulo.setAttribute("class", "activo");  // cambia un atributo
titulo.style.color = "#780EA9";          // cambia un estilo
titulo.classList.add("resaltado");       // añade una clase

Eventos

Un evento es una acción que ocurre en la página (un clic, escribir en un campo, enviar un formulario, mover el mouse…). Se "escuchan" con addEventListener:

const boton = document.querySelector("#guardar");

boton.addEventListener("click", function (e) {
    e.preventDefault();          // evita el comportamiento por defecto
    alert("¡Botón presionado!");
});

Eventos muy usados: click, submit, input, change, keydown y DOMContentLoaded.

¿Dónde se usa el DOM en este repositorio?

El módulo de café ya no usa el DOM en el navegador: ahora es un sistema PHP + MySQL que se ejecuta en un servidor. Aun así, el patrón del DOM sigue presente en su interfaz: el JavaScript del cliente valida formularios y hace cálculos dinámicos de totales, mientras que PHP genera el HTML del lado del servidor.
