🌐 HTML: el lenguaje de marcado que estructura la Web


HTML (HyperText Markup Language) no es un lenguaje de programación; es un lenguaje de marcado que define la estructura y el significado del contenido. Mediante etiquetas, encerramos partes del contenido para que se comporten o se muestren de determinada manera.

📌 ¿Qué es un elemento HTML?

Un elemento HTML se compone de:

  1. Etiqueta de apertura: nombre del elemento entre paréntesis angulares <p>. Marca el inicio.
  2. Etiqueta de cierre: igual pero con barra diagonal </p>. Indica el final.
  3. Contenido: texto, imágenes u otros elementos.
  4. Elemento = etiqueta apertura + contenido + etiqueta cierre.

🔹 Ejemplo de párrafo

<p>Este es un párrafo de ejemplo.</p>

Las etiquetas pueden convertir una palabra en hipervínculo, aplicar negrita, cursiva, etc.

🧱 Estructura fundamental de un documento HTML

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Título de la página</title>
  </head>
  <body>
    <!-- Contenido visible -->
  </body>
</html>
  • <!DOCTYPE html> — Declaración obligatoria (hoy en día asegura el modo estándar).
  • <html> — Elemento raíz que envuelve todo el contenido.
  • <head> — Contenedor de metadatos: título, codificación, estilos, etc. (no visible).
  • <meta charset="utf-8"> — Define el juego de caracteres universal (UTF-8).
  • <title> — Título que aparece en la pestaña del navegador.
  • <body> — Todo el contenido que se muestra al usuario (texto, imágenes, vídeos…).

✍️ Etiquetas de formato de texto

HTML ofrece elementos para dar jerarquía y énfasis al texto.

📝 Edición de contenido en vivo

El atributo global contenteditable convierte cualquier elemento en editable:

  • contenteditable="true" → editable
  • contenteditable="false" → bloqueado
  • contenteditable (vacío) → se interpreta como true

⚙️ Elementos interactivos

Permiten al usuario introducir datos, realizar acciones y modificar la página.

📋 Formularios y controles de entrada (<form>)

<input> es el más versátil; su comportamiento lo define el atributo type.

Tipos de <input> destacados

  • Texto: text, password, email, search, tel, url, number.
  • Selección: checkbox (múltiple), radio (única).
  • Fecha / hora: date, time, datetime-local, month, week.
  • Controles especiales: color (selector), range (deslizador), file (archivo).
  • Botones: submit, reset, button.
  • hidden (oculto) e image (botón gráfico).

Otros controles importantes

  • <textarea> → campo multilínea.
  • <select> y <option> → menú desplegable.
  • <button> → botón personalizable.
  • <datalist> → sugerencias para un <input>.
  • <output> → muestra resultado de un cálculo.
  • <fieldset> + <legend> → agrupan controles.
  • <label> → etiqueta asociada a un control (mejora accesibilidad).
  • <meter> y <progress> → medición y progreso.

🖼️🎵 Elementos multimedia

HTML permite incrustar imágenes, audio, vídeo y contenido externo.

🖼️ Imágenes y gráficos

  • <img> — imagen simple.
  • <figure> + <figcaption> — imagen con leyenda.
  • <picture> — múltiples fuentes para diseño responsivo.
  • <map> y <area> — mapa de imagen con zonas cliqueables.
  • <canvas> — área de dibujo con JavaScript (gráficos, juegos).
  • <svg> — gráficos vectoriales escalables.

🔊 Audio y Vídeo

  • <audio> — reproduce archivos de audio.
    (placeholder)
  • <video> — reproduce vídeo.
  • <source> — ofrece múltiples formatos para <audio>, <video> y <picture>.
  • <track> — pistas de texto (subtítulos, descripciones).

📦 Contenido externo / incrustado

  • <iframe> — incrusta otra página HTML (documento anidado).
  • <embed> — contenido externo (PDF, plugin).
  • <object> — recurso externo genérico.
  • <portal> — navegación fluida (experimental).
