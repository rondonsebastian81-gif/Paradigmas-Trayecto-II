¿Qué es CSS?

[span_0](start_span)

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada) y es el lenguaje que se utiliza para dar estilo a las páginas web[span_0](end_span). [span_1](start_span)Con CSS puedes cambiar el color, la tipografía, el tamaño, el espaciado, la disposición y muchos otros aspectos visuales[span_1](end_span).

Sintaxis

[span_2](start_span)[span_3](start_span)

La sintaxis básica de CSS se compone de reglas[span_2](end_span)[span_3](end_span):

Selector {
    Propiedad: Valor;
}
    [span_4](start_span)
  • Selector: Indica el elemento o elementos HTML a los que se aplica la regla[span_4](end_span).
    • [span_5](start_span)
  • Declaración: El conjunto de estilos que se aplican al selector (todo lo que está dentro de los corchetes)[span_5](end_span).
    • [span_6](start_span)
  • Propiedad: La característica que se desea modificar[span_6](end_span).
    • [span_7](start_span)
  • Valor: El valor que se establece para esa propiedad[span_7](end_span).
[span_8](start_span)

Puedes incluir tantas reglas y propiedades como necesites en tu archivo[span_8](end_span).

Formas de aplicar CSS

[span_9](start_span)

Existen tres métodos principales para aplicar estilos a una página web[span_9](end_span):

    [span_10](start_span)
  • CSS en línea: Se aplica directamente en el atributo style de un elemento HTML[span_10](end_span).
    <h1 style="color: blue; font-size: 24px;">Hola, mundo!</h1>
    • [span_11](start_span)
  • CSS interno: Se incluye dentro de una etiqueta <style> dentro del <head> del documento[span_11](end_span).
    • [span_12](start_span)
  • CSS externo: Se crea un archivo .css separado y se enlaza al HTML mediante una etiqueta <link> en el <head>[span_12](end_span).
    <link rel="stylesheet" href="styles.css" />
